    🔌 MCP 接入步骤
    
          
      
            
    1. 绑定 BIP 凭据：切到「BIP 凭据」→ 填账号密码 → 保存（一次绑定，之后 agent 报工无需再传账号密码）
      2. 
            
    2. 生成接入密钥：切到「接入密钥」→ 填名称（如 zcode）→ 生成，复制一次性的 bip-xxx 明文
      3. 
            
    3. 复制配置：「MCP 配置」里复制完整 JSON（含密钥），或切「手动模式」按字段复制
      4. 
            
    4. 填入客户端：把 JSON 或字段粘贴到你的 agent 的 MCP 客户端配置（Claude Code / Codex / BR-Agent 自定义连接器…）
      5. 
            
    5. 验证：agent 调用 bip_preview 查考勤，确认能正常返回
      6. 
          
    
          
    每个员工密钥互不可见、BIP 凭据相互隔离；密钥吊销后立即失效。MCP 端点：http://<服务器内网IP>:51889/mcp
    
        
    

        
    
          
    🧰 MCP 工具一览
    
          
      
            
    • bip_preview — 报工预览（考勤四分类 + 报工单概况 + 表单数据，一次返回）
      • 
            
    • bip_scan / bip_submitted — 考勤扫描 / 已提交报工单查询
      • 
            
    • bip_report / bip_auto_report / bip_split_report — 单日 / 批量 / 拆分报工
      • 
            
    • bip_form_data / bip_list_phases / bip_sync_options — 表单与选项
      • 
            
    • bip_delete_doc / bip_revoke_doc — 删除 / 撤销报工单
      • 
            
    • bip_set_credentials — 通过 agent 绑定 / 更新 BIP 凭据（也可在平台页面操作）
      • 
          
    
          
    所有 bip_* 工具按连接密钥所属用户隔离；未绑定 BIP 凭据时工具会提示先绑定。
